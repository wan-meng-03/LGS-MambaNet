# LGS-MambaNet

LGS-MambaNet is a skin lesion image classification model based on MambaVision-T. It combines local–global selective state-space modeling with orthogonal fusion of lesion detail and semantic features.

## Repository Contents

- Training and evaluation scripts, configuration files, and dataset loading and preprocessing utilities.
- Five-fold split lists for HAM10000, ISIC2019, Derm7pt, and PAD-UFES-20.

## Code Release

The LGS-MambaNet model implementation will be released in this repository upon acceptance of the paper.
